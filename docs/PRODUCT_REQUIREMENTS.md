# 製品仕様の検討事項

EPUB リーダーの実装・完了条件を決める際に、ユーザーと確認する事項を記録する。
未チェックの項目は未決定であり、対応済みの仕様や合意済みの目標ではない。チェック済みの項目は仕様の合意を示し、実装済みを意味しない。関連する開発の計画時に決定し、採用理由と検証方法を追記する。

## EPUB の対応範囲

- [x] EPUB 2・3、DRM のない横書きリフロー型を初回対象とする。縦書き・固定レイアウト・DRM・音声・動画は対象外。
- [x] 本文 XHTML と標準の `ruby`・`rt` を保持し、書籍内の PNG・JPEG・GIF・CSS を取得する。実際の表示・CSS の適用範囲は本文表示の計画で決定・検証する。
- [x] 読み取り不能・破損・非対応を区別して返す。リソース欠落も検証する。表示文言・UI は本文表示の計画で決める。
- [x] 自作の EPUB 2・3、目次と読み順が異なる書籍、画像・ルビ入り、破損・非対応書籍で取得を自動検証する。
