# 製品仕様の検討事項

EPUB リーダーの実装・完了条件を決める際に、ユーザーと確認する事項を記録する。
以下は未決定であり、対応済みの仕様や合意済みの目標ではない。関連する開発の計画時に決定し、採用理由と検証方法を追記する。

## EPUB の対応範囲

- [ ] 対応する EPUB のバージョンと、対象外とする形式。
- [ ] リフロー型・固定レイアウト、縦書き、ルビ、画像などの対応範囲。
- [ ] 非対応・破損ファイルを読み込んだ場合の表示と動作。
- [ ] 対応範囲の確認に使う書籍・テストデータ。

## 大きな書籍での性能目標

- [ ] 対象とするファイルサイズ、章数、画像量などの条件。
- [ ] 読み込み時間、ページ移動の応答時間、メモリ使用量の目標。
- [ ] 計測に使用する環境と書籍・テストデータ。

## 読書履歴・設定の保存と削除

- [ ] 保存する情報（読書位置、履歴、表示設定など）と保存するタイミング。
- [ ] 保存先、保存期間、アプリ再起動後の復元方法。
- [ ] 書籍の削除時に関連データをどう扱うか。
- [ ] 履歴・設定の個別削除や一括削除の方法。

## 決定・変更の記録

決定した内容、理由、関連する計画ファイル、検証方法を記録する。
