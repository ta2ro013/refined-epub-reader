# 横書きEPUBの共通CSSによる非対応の誤判定を修正する計画

- 作成日：2026-10-07。
- 状態：調査・再現済み。修正計画・開始承認済み。TDDでの修正・自動検証と対象EPUBの全39章の取得確認が完了。ユーザーによる対象EPUBの実アプリでの開く操作も確認済み。変更全体の人間のレビュー承認済み。[PR #5](https://github.com/ta2ro013/refined-epub-reader/pull/5) を作成済み・未マージ。
- 関連：[本文表示の計画（03）](20261007-03-reader-display.md)。3Cのレビュー中に発見したRust側の不具合を、3Cの10ファイルとは別の3ファイルの修正単位として扱う。

### 目的・背景

横書きのEPUBに横書き・縦書き両方の共通CSSルールが入っている場合、縦書き用ルールを使用していなくても非対応として拒否している。対象ファイルの書籍情報の読み込みは成功したが、既存の `Book::chapter(0)` は `Unsupported` を返した。アーカイブは正常で、暗号化の宣言はなく、確認した39文書には縦書き用のクラス・インライン指定がなかった。

### 問題・解決方法

- 採用：CSSの縦書き指定の検査で、現在の章に一致しない単純なクラスセレクターのルールを除外する。共通テンプレートの `.vrtl` や `html.vrtl` 等を、使用されている指定と混同しない。
- 維持：適用される縦書き指定、パッケージの縦書き・固定レイアウト宣言、DRM・音声・動画は引き続き非対応とする。
- 保守的に扱う：複雑なセレクターや入れ子等の適用関係を判断できない場合は、既存の判定を維持する。CSS全仕様の評価器をRustで新たに作る計画ではない。
- 棄却：縦書き検査をすべて削除する。承認済みの横書き限定の範囲を守れなくなるため。
- GPU警告に対する設定変更は本修正に含めない。今回の `Unsupported` は描画前のRustの章検査で再現している。

### 実装方針

- `src-tauri/src/book.rs` の縦書き判定を章のXML要素と組み合わせる。外部CSSとインラインのstyle要素に共通して適用する。
- `src-tauri/src/book_tests.rs` の自作fixtureで未使用ルールと使用ルールを検証する。新しい本番用依存関係は追加しない。
- 変更対象は上記2ファイルと本計画の3ファイル。3Cの画面接続は現在の変更を保持する。

### 修正・検証記録（2026-10-07）

- `book.rs` の縦書き検査で、スタイルシートの規則と現在の章のXMLを照合するようにした。単純な `.class`・`tag.class`・複数クラスとそのカンマ区切りだけは、実際の要素・クラスが一致しない場合に検査対象から除外する。直接のインライン指定と、使用される縦書きルールは引き続き拒否する。
- 複雑なセレクター、入れ子、壊れたCSSでは従来の拒否を維持する。文字列内の波括弧・エスケープを規則の境界と混同しない。CSSのカスケード全体を評価したり、縦書き書籍を対応範囲へ追加したりする変更ではない。
- RED：未使用クラスを含む共通CSS（EPUB 2・3）と文書内style要素のテストが `Unsupported` で失敗した。次に保守的な拒否の境界を検証し、未使用クラスの規則内に入れ子があるケースを誤って許可する失敗を確認した。
- GREEN：未使用の単純なクラス指定は許可し、入れ子等は拒否する最小限の修正で通した。実際に使われるクラス・複数クラス、一般セレクターを含むリスト、否定疑似クラス、media、壊れた規則、文字列内の波括弧を含む規則でも拒否を確認した。
- REFACTOR：コメント除去と縦書き宣言の検査を分離・共有し、既にコメントを除去した規則を再処理しないよう整理した。`cargo fmt` の後に全検証を再実行した。
- `cargo test --manifest-path src-tauri/Cargo.toml`：既存47件と追加3件の全50件成功。
- `cargo check --manifest-path src-tauri/Cargo.toml`：成功。
- `cargo build --manifest-path src-tauri/Cargo.toml`：成功。開発用のアプリ実行ファイルを再ビルドした。
- `bun --no-env-file run test`：3Cを含む全30件成功。
- `bun --no-env-file run build`：型チェック・フロントエンドビルド成功。
- 対象EPUBは元ファイルを変更せず、実際の `book.rs` を使った作業環境の診断用CLIで全39章の取得が成功した。本文や商用EPUBをリポジトリのfixtureには追加していない。
- 実アプリの画面での表示・標準ダイアログとGPU描画の動作はこの検証に含まない。修正前に確認済みのGPU警告の対策は追加していない。アプリを再起動して同じ書籍を選択し、表示を再確認する必要がある。Windows実機も未検証。

- ユーザーから、修正後の実アプリで対象EPUBを開けたとの確認を受けた。GPU警告が解消したこと、全ページの表示品質、ページ操作・サイズ変更・Windows実機を確認したという報告ではないため、これらを検証済みとは扱わない。
